# Content Manager

### The ultimate Assetto Corsa launcher and manager

Content Manager is the most comprehensive launcher and content management tool for Assetto Corsa. Install mods, manage car and track collections, set up online sessions, and access thousands of quality-of-life improvements.

<br>

---

## Features

| | |
|:---|:---|
| **Mod Manager** | Install, organize, and update cars, tracks, and skins with ease |
| **Enhanced Launcher** | Advanced launch options, graphics presets, and performance tuning |
| **Custom Shaders** | Integration with Custom Shaders Patch for stunning visual upgrades |
| **Online Hub** | Find and join online servers with advanced filtering and quick joining |
